# App Icon

The production icon master is `Assets/AppIcon-1024.png`. `scripts/generate-app-icon.sh` deterministically resizes it into the macOS asset-catalog slots and compiles the catalog with Xcode `actool`.

## Generation record

- Tool path: built-in ImageGen
- Use case: `logo-brand`
- Generated: 2026-08-27
- Source output was copied into the repository and normalized to 1024×1024.

Final prompt:

> A quiet, precise production macOS app icon for a local-only Korean-English keyboard layout correction utility. A centered typographic transition mark combining the exact Korean glyph “한” and uppercase Latin “A”, separated by one restrained vertical cursor stroke. Minimal premium vector-like raster, native macOS utility aesthetic, deep midnight indigo tile, warm off-white glyphs, cool-blue cursor accent. Generous safe margins. No keyboard illustration, padlock, cloud, AI sparkle, watermark, extra text, or photorealism.

## QA
